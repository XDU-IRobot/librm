# 功能与支持状态

以下清单保留已实现功能和待办项目，具体用法请参阅各模块教程。

### 跨平台支持

- [x] STM32 HAL
- [x] Linux PC (SocketCAN、boost::asio、timerfd后端)
- [x] Raspberry Pi / Orange Pi (libgpiod GPIO后端)
- [ ] Jetson

### 硬件抽象层 (HAL)

- CAN
  - [x] STM32 BXCAN
  - [x] STM32 FDCAN
  - [x] STM32 MCP2515 SPI-FDCAN
  - [x] Linux SocketCAN
- [x] ThrottledCAN：基于限流优先级队列的定频 CAN 发送封装
- GPIO
  - [x] STM32 HAL GPIO
  - [x] Linux libgpiod
  - [ ] Jetson
- Serial (UART)
  - [x] 异步/同步接口
  - [x] STM32 HAL(阻塞/IT/DMA)
  - [x] Linux boost::asio::serial_port
- [ ] SPI
- [ ] I2C
- Timer
  - [x] 轮询
  - [x] Linux timerfd
  - [x] STM32 TIM
- [ ] 统一IO操作模型：类boost::asio io_context

### 设备驱动

#### 电机

- [x] DJI 电机：GM6020 (电压控制+新固件电流控制) / M3508 + C620 / M2006 + C610
- [x] 达妙电机：MIT模式、速度位置模式、速度模式
- [x] HT04 电机：海泰 Cheetah MIT 开源关节模组
- [x] Unitree 电机：宇树系列电机
- [x] GO8010 电机：宇树 GO-M8010-6 电机
- [x] LK 电机：瓴控系列电机（MS、MF、MG、MH）
- [x] 本末电机：仅测试过p1010b_111，理论上协议通用
- [x] 张大头步进驱动
- [x] Hiwonder 幻尔总线舵机

#### 传感器

- [x] BMI088 六轴 IMU
- [x] IST8310 三轴磁力计
- [x] Hipnuc IMU (串口 + CAN双协议)
- [x] 维特智能 JY-ME02-CAN 角度编码器，CAN协议版本
- [x] STP23L 激光测距模块
- [x] ZNSV6T1 数字称重模块（Modbus-RTU over RS485）

#### 遥控

- [x] DR16 接收机
- [x] 通用 SBUS 协议遥控接收机
- [x] VT03 图传链路遥控

#### 其他

- [x] 裁判系统 - 支持协议版本 v1.6.4 / v1.7.0 / 新v1.1.0 / 新v1.2.0，可切换
- [x] 超级电容 - 2024 赛季超级电容 CAN 协议 + 港科开源超级电容 CAN 协议

#### 设备框架
